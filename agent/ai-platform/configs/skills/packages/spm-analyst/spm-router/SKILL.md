# 超市总控路由（所有超市问数先过这里）

## 0. 执行契约（硬约束）

```
超市 Worker（本组 Skill）→ iqd__ask → iqd 编排层 → WrenAI → StarRocks（sm-data）
```

| # | 约束 | 违反后果 |
|---|------|----------|
| 1 | **只通过 `iqd__ask` 取数** | 禁止直连 WrenAI / 业务库 / 自写 SQL |
| 2 | **必须显式传 `connection_id=sm-data`** | 缺省会落到默认连接 → **查错库**；禁止改传 `bg-data` |
| 3 | `question` 传**规范问句**（不改变语义；补槽位与术语规范化允许） | 样本召回失败 / 选表打分退化 |
| 4 | **禁止解析或校验 SQL** | `view=user` 下拿不到 SQL |
| 5 | **禁止委派其他智能体** | Worker `max_depth=1` |
| 6 | 多轮追问传 `thread_id` | 上下文丢失 |

### 改写铁律

1. **保留中文业务词**（销售/门店/生鲜/报损/会员），不要改成英文列名。
2. **不要加 `【S#】` 前缀** —— 超市样本库是自然语言问法（见 `18_WrenAI样本抄录清单`），前缀是噪音。
3. 问法尽量自带 **日期 + 门店**（样本槽位：`2026-06-15` + `宜兴城中店` / `store_id=0001`）。

## 1. 处理流水线

```
用户提问
 → ① 硬缺口 / 越界拒答（§3）
 → ② 问题域路由（§2，命中即停）
 → ③ 槽位检查：缺日期或门店 → 追问，禁瞎查
 → ④ 加载 spm-ask，按域改写规范问句
 → ⑤ iqd__ask(connection_id=sm-data, question=规范问句, thread_id=…)
 → ⑥ 结果校验 + 按 spm-ask 模板回答
```

## 2. 问题域路由（主题优先于切分 · 命中即停）

> 分类树回答「这题问的是什么指标」，不是「用了哪张表」。  
> 「各大类 / 生鲜 / 门店」只是 SQL 的 `data_type` / `goodstype` 槽位。

| 优先级 | 判定线索 | 路由域 | 回归示例 |
|---:|---|---|---|
| 0 | 硬缺口词（§3） | **拒答** | 损耗吃掉多少毛利；日清/鲜度/临期；动销率；坪效；人效；客流转化；促销 ROI |
| 1 | 毛利/毛利率/前台毛利/损耗/报损/报损率/亏/盈亏 | **毛利与损耗** | 生鲜报损率；前台毛利 |
| 2 | 会员/会员销售/会员占比/会员人数 | **会员经营** | 各大类会员消费人数 → 仍归会员 |
| 3 | 新品/重点/TOP/爆品 | **商品属性** | 新品占多少销售 |
| 4 | 促销/折扣/打折/出清/券 | **促销与出清** | 各大类促销商品占比 → 仍归促销 |
| 5 | 生鲜（且主题是销售额/占比/有销小类，非毛利损耗） | **生鲜品类** | 生鲜销售额 |
| 6 | 类目/大类/中类/小类/品类 + 销售排名/占比 | **分类分析** | 各大类销售额排名 |
| 7 | 门店总盘（营业额/去券销售额/客单） | **经营日报** | 宜兴城中店销售额和营业额 |
| 8 | 兜底 | **经营日报** | 主题不明但可识别为超市经营问数 |

**交叉问法唯一答案**：主题词优先于切分词。

| 问法 | 归类 |
|---|---|
| 各大类会员消费人数 | 会员经营 |
| 各大类促销商品销售占比 | 促销与出清 |
| 生鲜类目前台毛利 / 生鲜报损率 | 毛利与损耗 |
| 各大类里哪些是生鲜、生鲜占比 | 生鲜品类 |

一句多问 → 拆两次 `iqd__ask`，回答分行呈现。

## 3. 硬缺口拒答（零编造）

命中即拒，**不要调 `iqd__ask` 硬查**：

| 类型 | 典型问法 | 正确 / 可替代口径 |
|---|---|---|
| 科目关系错 | 损耗吃掉多少毛利 | 损耗与毛利独立科目；可答纯损耗报损率 |
| 字段不存在 | 生鲜日清 / 鲜度 / 临期 | 可答生鲜毛利、报损率（四口径）、盈亏 |
| 缺分母 | 动销率 | 可答有销售小类数 |
| P0 缺口 | 坪效、人效、客流转化、真实促销 ROI、价格弹性 | 拒答并说明缺表 |
| 跨业态 | 百购×超市合并对比 | 拒答；百购问题建议百购分析智能体 |
| 百购本域 | 百货商场/厅房/客流车流/企微私域 | 拒答并建议 `bgbh-analyst` |

拒答话术：「当前数据答不了「{问法}」（{理由}）。可改问：{可替代}。」

## 4. 槽位

| 槽位 | 必填 | 默认 | 说明 |
|---|---|---|---|
| 日期 | ✅ | 无默认；缺则追问 | 样本用绝对日期；禁止 silently 用「昨天」查数不声明 |
| 门店 | ✅（单店问法） | 无默认 | 样本店：`宜兴城中店` / `0001` |
| data_type 档 | 改写时声明 | 门店总盘→门店；类目→大类/小类 | 回答必须声明档位 |

## 5. 结果校验

1. 空结果 → 声明条件后如实说暂无数据；不编数。
2. `45204` → 无权限，不重试换表。
3. 报损类 → 检查是否四口径齐全；单日是否声明盘点日性质。
4. 两次 `iqd__ask` 失败 → 「暂时没查准，已记录原文」，禁止编造。

## 6. 验收用例（路由层）

| 问法 | 期望 |
|---|---|
