# 超市取数（MVP · 合并问题域）

前置：已加载 `spm-router` 且路由域不是「拒答」。

## 调用

```
iqd__ask(
  question=<下方改写后的规范问句>,
  connection_id=sm-data,
  thread_id=<追问时透传>
)
```

可选：先 `iqd__describe_scope(connection_id=sm-data)` 说明可问范围。

## 依赖表（上线前置 · 须已 in_scope）

| 表 | 角色 |
|---|---|
| `ads_spm_trd_cpi_category_day_df` | 销售金额与数量主源（营业额/去券/客单） |
| `ads_spm_trd_sale_category_day_df` | 属性拆分 + 会员 + 折扣/券 |
| `ads_spm_trd_cost_category_day_df` | 毛利与损耗唯一源 |
| `dim_spm_chl_category_df` | 类目维表（生鲜判定 / 名称） |

## 三表硬纪律（改写与回答都必须遵守）

1. **必带 `data_type`**：默认门店；类目用大类/中类/小类。不带 → 跨档翻倍。
2. **比率加权**：`SUM(分子)/SUM(分母)`，禁 `AVG(率)`。
3. **跨表 join 同档**：且带 `data_type` 等值。
4. **`xsje` 双义**：cpi=去券；sale=非去券。
5. **毛利率**：`SUM(cost.qtml)/SUM(cpi.turnover_amt)`（cost 无销售额列）。
6. **报损率**：分子 `cost.shhsje`、分母 `cpi.xsje`，各自聚合后再比。
7. **`cust_cnt`**：sale 表为 string → 聚合须 CAST（由样本/模型侧保证；回答勿自行算错）。
8. **生鲜判定**：`goodstype='1' AND deptlevelid='4'`（小类层）；回答声明生鲜含日配加工/乳品/粮油（维表口径）。

## 按域改写模板（对齐已入库样本问法）

> 尽量贴近样本标准问法，利于 few-shot 召回。缺日期/门店先追问，不要 silently 填。

| 域 | 规范问句示例 |
|---|---|
| 经营日报 | `{日期} {门店}的销售额和营业额是多少？` |
| 分类分析 | `{日期} {门店}各大类的销售额排名` / `…销售额占比是多少？` |
| 生鲜品类 | `{日期} {门店}生鲜销售额是多少？` / `…各大类里哪些是生鲜？生鲜销售额占比多少？` |
| 商品属性 | `{日期} {门店}新品、重点、TOP 商品各占多少销售？` |
| 促销与出清 | `{日期} {门店}各大类折扣金额构成` / `…各大类促销商品销售占比` |
| 会员经营 | `{日期} {门店}会员销售占比` / `…各大类会员消费人数` |
| 毛利与损耗 | `{日期} {门店}前台毛利和毛利率`；`…损耗金额和损耗率`；`…生鲜类目的前台毛利`；`{年月} {门店}生鲜的报损率`；`…损耗最高的类目`；盘点日单日报损须保留原日期 |

样本店名：**宜兴城中店**（`0001`）。抽测基准日常用 **`2026-06-15`**；月度报损用 **`2026年6月`**；盘点日样本 **`2026-06-14`**。

## 口径速查

| 用户说法 | 落点 |
|---|---|
| 营业额 | cpi.`turnover_amt` |
| 销售额（经营总盘语境） | cpi.`xsje`（去券）——须在回答声明 |
| 会员销售占比分母 | sale.`turnover_amt`（已定稿） |
| 折扣金额 vs 促销打折 | `discvalue` vs `disc_value`（仅差下划线，须区分） |
| 报损率 | **四口径并列**：纯损耗/绝对值 × 全期/常态；常态剔盘点尖峰日 |
| 单日 06-14 报损 | 先声明盘点日账实双向重算，不可说「损耗严重」；给常态区间参照 |

## 回答模板

1. **现状**：日期、门店、指标、数值；声明 **data_type 档 + 分母口径**。
2. **结构/明细**：排名或占比表（若工具返回多行）。
3. **口径提醒**：生鲜宽度、报损四口径、盘点日性质等，按问题需要写出。
4. **行动**：只给一个下钻建议（如「要不要看各大类排名 / 常态报损率」）。
5. **禁止**：输出 SQL；编造同比；把损耗说成毛利扣减。
