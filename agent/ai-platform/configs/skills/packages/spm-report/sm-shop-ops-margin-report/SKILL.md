## 1. 数字单位与话术铁律

| 类型 | 展示 |
|------|------|
| **金额**（营业额/成本/毛利额/费用/盈亏/低毛利主营等） | 元÷10000 → **万元**，**2 位小数**，后缀 `万元` |
| 毛利率 / 占比 / 损耗率 | 百分数，1 位小数 + `%`（接口 0～1 则 ×100） |

**禁止**：把损耗说成「吃掉了多少毛利」；未确认阈值喊「异常」；臆造盘点尖峰日期。禁止 HTML；勿对用户说字段名。

## 2. 毛利瀑布展示规则（强制）

瀑布表**禁止**只写「并列调整」。每一行必须让人看懂：**金额多少、对毛利是增还是减、增减多少**。

### 2.1 列定义

| 列 | 内容 |
|----|------|
| **环节** | 营业额 / 销售成本 / 前台毛利 / 各调整项 / 综合毛利 |
| **本期金额** | 接口原值换算万元（绝对值展示亦可，但影响额必须带符号语义） |
| **对毛利** | `🟢增` / `🔴减` / `—`（节点行） |
| **影响额** | 增减多少毛利：`+x.xx 万元` / `−x.xx 万元` / `—` |

### 2.2 默认方向（含税主口径；按业务语义，勿改口胡说「吃毛利」）

| 环节 | 对毛利 | 影响额怎么写 |
|------|--------|--------------|
| 营业额 | — | —（起点） |
| 销售成本 | 🔴减（相对营业额，构成前台毛利） | `−` 成本额 |
| 前台毛利 | — | 节点：营业额 − 销售成本（有数可一句验算） |
| 后台费用 | 🔴减综合毛利 | `−` 费用额 |
| 供应商分担 | 🟢增综合毛利 | `+` 分担额 |
| 配送加价 | 🟢增综合毛利 | `+` 加价额 |
| 物流分摊 | 🔴减综合毛利 | `−` 分摊额 |
| 股权调整 | **跟接口符号**：正→🟢增，负→🔴减（取绝对值写影响额） | `+`/`−` \|金额\| |
| 综合毛利 | — | 终点 |

> 科目仍是并列入账，不是「损耗吃毛利」。这里「增/减」只表示**相对综合毛利的方向**，方便阅读。  
> 若接口对某调整项已带正负号且与上表冲突：**以接口符号为准**，并在该行说明「按取数符号」。

### 2.3 必写差额行

在综合毛利后（或表下）固定一行：

- **前台→综合差额** = 综合毛利 − 前台毛利（万元，带 `+`/`−`）
- 用 1 句点出：**差额主要来自哪 1～2 个影响额最大的调整项**（按影响额绝对值排序）

去税口径仅当用户追问或主表注明「去税并列」时再附；默认含税。

## 3. 版式骨架

```markdown
## {店名} · {时间标签} · 毛利与损耗

### 毛利瀑布
| 环节 | 本期金额 | 对毛利 | 影响额 |
|------|----------|--------|--------|
| 营业额 | **232.56 万元** | — | — |
| 销售成本 | **204.06 万元** | 🔴减 | **−204.06 万元** |
| 前台毛利 | **28.50 万元** | — | — |
| 后台费用 | **3.20 万元** | 🔴减 | **−3.20 万元** |
| 供应商分担 | **5.10 万元** | 🟢增 | **+5.10 万元** |
| 配送加价 | **1.20 万元** | 🟢增 | **+1.20 万元** |
| 物流分摊 | **0.80 万元** | 🔴减 | **−0.80 万元** |
| 股权调整 | **0.40 万元** | 🟢增 | **+0.40 万元** |
| 综合毛利 | **31.20 万元** | — | — |

**前台→综合差额：** **+2.70 万元**（综合 − 前台）。主要来自供应商分担（+5.10），被后台费用（−3.20）等部分抵消。

> 无瀑布结果则整节省略。

### 生鲜占比与盈亏
| 指标 | 本期 |
|------|------|
| 生鲜营业额 / 占门店 | **xx.xx 万元** / **x.x%** |
| 生鲜主营 / 占门店 | … |
| 生鲜前台毛利 | … |
| 生鲜盈亏（含税） | … |
| 常规盈亏（含税） | … |

> 口径：类目 id 以 `1` 开头；有 `meta.freshCategoryRule` 可一句转述。无 Fresh 则整节省略。

### 低毛利预警
| 指标 | 本期 |
|------|------|
| 低毛利率主营销售 | **xx.xx 万元** |
| 占主营 | **x.x%** |

> **仅 week/month**。无 Alert 或日粒度 → 整省或注明「仅支持周/月」。

### 毛利损耗快览（可选）
有 overview 且需环比对照时：前台/综合毛利额·率、损耗额·率 3～6 行；有瀑布时从简。

### AI 诊断小结
2～4 句；最多 3 个「核心关注」（可点名「某某调整项减毛利 x 万」）。
```

## 4. 内部字段对照（勿对用户说出）

## 5. 关注点（草稿）

| 关注 | 说明 |
|------|------|
| 综合低于前台（差额为负） | 点名影响额最大的🔴减项；勿归因损耗 |
| 综合高于前台 | 点名🟢增项（如供应商分担、配送加价） |
| 生鲜盈亏恶化 | 对照占比；勿编造时段/日清 |
| 低毛利主营占比升高 | 结构风险；阈值待确认 |
