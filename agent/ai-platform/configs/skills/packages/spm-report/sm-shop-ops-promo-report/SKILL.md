# 促销专项主题分析（sm-shop-ops-promo-report）

独立主题服务。用户明确要「促销专项 / 折扣三列 / 出清 / 供应商分担」时加载。  
**禁止** `skill` 其它 ops-report。弱问仅促销占比 → overview-report。P2～P4 品类侧 → category-report，禁止本 Skill。

- 槽位齐后：`skill(sm-shop-sale)` → S2/S3/S4，对照一期，并行。
- 成文后禁止再 MCP；禁止编造未取数。

---

## 1. 版式

**金额**（总折扣/促销打折/处理打折/出清额/分担额等）：元÷10000 → **万元**，**保留 2 位小数**，后缀 `万元`。  
比率/回收比按原口径；无客单价则不适用「元」例外。

周/月列名用「较上一周/月」；日用「较上期」。对比列规则与 overview 相同：**本期只写绝对值，对比列只写升降比例**（金额 `%`，比率 `pp`），禁止写对比期绝对值。

```markdown
## {店名} · {时间标签} · 促销专项

### 促销结构
| 指标 | 本期 | 较上一周 | 较同期 |
|------|------|----------|--------|
| 总折扣 | **12.35 万元** | 🔴↑ +196.3% | … |
| 促销打折 | **8.20 万元** | 🔴↑ +204.5% | … |
| 处理打折 | **1.05 万元** | 🔴↑ +134.5% | … |
| 总折扣率 | **36.3%** | ↑ +17.5pp | … |
| 出清销售占比 | **12.3%** | ↓ -0.9pp | … |
| 出清回收比 | **0.85** | ↓ 0.85 vs 0.64 | … |
| 供应商分担金额 | **11.04 万元** | 🟢↑ +417.8% | … |
| 供应商分担率 | **36.2%** | ↑ +9.0pp | … |

### AI 诊断小结
**核心关注：** …
```

仅输出**本轮已取到**的指标行；缺接口则整行省略并在小结说明「未查折扣/出清/分担专项」。

### 1.1 对比列（强制）

S2/S3/S4 **无现成环比字段**，必须用本轮已取的两期 `summary` **自己算**：

| 行 | 字段（两期同名字段相减） | 对比列 |
|----|--------------------------|--------|
| 总折扣 | `totalDiscAmt` | 金额相对差 `%` |
| **促销打折** | `promoDiscAmt` | 金额相对差 `%` |
| **处理打折** | `clearanceDiscAmt` | 金额相对差 `%` |
| 总折扣率 | `totalDiscRate` | 百分点 `pp` |
| 出清销售占比 | `clearSalesRatio` | `pp` |
| 出清回收比 | `clearanceRecoveryRatio` | 可写 `本期 vs 上期绝对值`（无量纲）或相对差 |
| **供应商分担金额** | `supplierShareAmt` | 金额相对差 `%` |
| 供应商分担率 | `supplierShareRate` | `pp` |

**禁止**：两期都已取到（如 44 周 + 43 周）时，促销打折 / 处理打折 / 供应商分担金额（或比率）填 `—`。  
`—` **仅**当该对比期**没有**对应 apiName 回包时使用。  
禁止用「总折扣有环比、拆列就空着」；三列折扣与分担金额只要本期行在表里，对比期有数就必须填比例。

折扣/分担额升高偏中性观察（结构），可不标 🟢/🔴；出清回收比下降需点名。

## 2. 关注点（草稿）

| 关注 | 说明 |
|------|------|
| 折扣结构 | 总折扣 vs 促销打折 vs 处理打折勿混用字段 |
| 出清 | 回收比远离 1 时提示 |
| 供应商分担 | 分担率偏低时提示 |
| 与总览促销占比 | 有 overview 促销占比时可一句对照 |

阈值待业务确认；未确认不喊「异常」。

## 3. 自检

- [ ] 未查数；未编造未取数字段  
- [ ] 三列折扣口径未混淆（总折扣 ≠ 促销打折 ≠ 处理打折）  
- [ ] 已取上期/上周时：促销打折、处理打折、供应商分担**金额**对比列不是 `—`  
- [ ] 对比列只有升降比例（或回收比的两期对照），无对比期万元绝对值
