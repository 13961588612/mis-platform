# 门店经营月报（sm-shop-ops-month-report）

独立服务。模板 `SPM-STORE-MONTH-REPORT` 绑本 `skill_id`。  
**禁止** `skill` 任何其它 `sm-shop-ops-*-report`。日报 → diary-report；周报 → week-report。  
槽位齐不问。同月多接口 **同一轮并行**。失败/truncated 禁止同参重试。成文后禁止再 MCP。

## 0. 日历闸门（先于一切销售查询）

**禁止**用公历推算「第几月」、自造 `ordMonth`、或先打 `getShopSaleOverview` 试探月是否存在。 MCP 的 `apiName` 用下表右列，禁止把 `S1` 当接口名。

| 代号 | 含义 | 工具 | apiName |
|------|------|------|---------|
| S1 | 经营总览 | `callShopSaleApi` | `getShopSaleOverview` |
| S2 | 折扣三列 | 同上 | `getDiscountStructure` |
| S3 | 出清 | 同上 | `getClearanceEfficiency` |
| S4 | 供应商分担 | 同上 | `getSupplierPromoShare` |
| S7 | 库存订货 | 同上 | `getShopInventoryOverview` |
| S8 | 毛利瀑布 | 同上 | `getMarginWaterfall` |
| S9 | 生鲜 | 同上 | `getFreshOverview` |
| S10 | 低毛利 | 同上 | `getLowMarginAlert` |
| P1 | 品类总览 | `callShopCategorySaleApi` | `getShopCategoryOverview` |
| P8 | 四象限 | 同上 | `getShopCategoryRoleMatrix` |
| P9 | ABC | 同上 | `getShopCategoryAbc` |

1. `skill(sm-common-info-calendar)` → **`listYearMonths`**（`year` = 目标年）。跨年对照再打对照年 **1 次**。
2. 清单行才是合法业务月。`ordMonth` / `startDate` / `endDate` **原样**写入销售 params。
3. 要查的每一个月键（本期、上一月）必须先在清单里命中。
4. **不在清单 → 该键一律不查销售**，禁止换相邻月试探、禁止循环 `apiName`。
5. 本期不在清单 → **整报停**，只说该业务月系统无此月。
6. 对照月不在清单 → 仍可查本期；「较上一月」写无对照，禁止再猜一个月。
7. 销售接口报「未找到该月」→ **该键停**，即使清单有该行也不换月重试。

上一月 = 同年清单里、本期行的**前一条**；本期是该年第一月则用上一年 `listYearMonths` 的**最后一条**。禁止 `月份 − 1` 或臆造 `202601` 这类键。

月内各周走势（仅用户点名）：再 `listYearWeeks`，**只**用清单内且落在该业务月起止内的周；周键不在周清单则不查。

## 1. 查数

闸门通过后再 `skill(sm-shop-sale)` 与 `skill(sm-shop-category-sale)`。

| | 规则 |
|--|------|
| 粒度 | 只 `period=month` |
| 本期 | 上表各 apiName **1 次**（P5/P6 可选，不在上表则不要编造） |
| 对照 | **只上一月**（须已在清单）同批各 1 次。不要去年同月，除非用户明确要同比 |
| 按周对比 | 仅用户要「月内各周」时：**只**周清单内各周 S1 写在总览；禁止按周扫促销/毛利/库存/品类 |
| 禁止 | 为「完整」拆成月内每一周去扫非 S1；打清单外的月 |

## 2. 数字与对比列（强制）

| 类型 | 展示 |
|------|------|
| 金额（不含客单价） | 元÷10000 → **万元**，2 位，后缀 `万元` |
| 客单价 | **元**，2 位，后缀 `元` |
| 客单数 | 整数 |
| 比率（本期列） | 1 位 `%`（接口 0～1 则 ×100） |

| 列 | 内容 |
|----|------|
| 本期 | **只写绝对值** |
| 较上一月 | **只写升降比例**；禁止写对照期绝对值 |

金额/客单：`↑ +x.x%` / `↓ -x.x%` / `持平`。率/占比：`pp`。  
越高越好：升 🟢 / 降 🔴。损耗：升 🔴 / 降 🟢。促销占比中性。持平不加色。  
两期都有回包禁止该格 `—`。S2～S4、S7、S9、S10 无现成环比，用两期 `summary` 自算。勿说损耗「吃毛利」。禁止 HTML。
