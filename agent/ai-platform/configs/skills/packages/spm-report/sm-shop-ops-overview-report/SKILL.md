# 经营总览主题分析（sm-shop-ops-overview-report）

独立主题服务。用户只要「经营总览 / 晨会」时由 router 加载本 Skill。  
**禁止** `skill` 其它 ops-report。用户要日报/周报/月报 → 告诉应走 diary/week/month，不要在本 Skill 里拼综合。

- 槽位齐后：`skill(sm-shop-sale)` → `getShopSaleOverview`。日：本期+上周同期（不查前一天）；周/月：本期+上一期。并行。
- 只写晨会两表（销售 + 轻量毛利损耗 + 促销占比）。瀑布/生鲜/低毛利 → 用户应改走 margin-report，本表不展开。
- 促销三列深拆 → promo-report。S1a/S1b 有数则轻量句。
- 成文后禁止再 MCP。

## 1. 版式（Markdown）

禁止 HTML。标题示例：`宜兴城北店 · 2026-11-05（周四）· 经营总览`。

### 1.0 数字单位（强制）

| 类型 | 展示 |
|------|------|
| **金额**（营业额/去券/主营/毛利额/损耗额/促销额等，**不含客单价**） | 元÷10000 → **万元**，**2 位小数**，后缀 `万元` |
| **客单价** | **元**，2 位小数，后缀 `元` |
| 客单数 / 人数 | 整数 |
| 比率 / 占比（当日列） | 百分数，1 位小数 + `%` |

### 1.1 对比列规则（强制）

| 列 | 内容 |
|----|------|
| **当日**（或本期） | **只写绝对值**（按 §1.0） |
| **较上周同期**（日报） | **只写升降比例**；**暂不写较前一天**、不查前一天 |
| **较上一周/月**（周月报） | **只写升降比例**，禁止写对照期绝对值 |

升降写法 + **红绿标记**（纯 MD 无 CSS，用 🟢/🔴；贴在比例旁）：

| 指标类型 | 对比列 |
|----------|----------------------|
| 金额、客单数、客单价 | `↑ +x.x%` / `↓ -x.x%` / `持平`（相对差 %） |
| 毛利率、损耗率、促销占比等 | `↑ +x.xpp` / `↓ -x.xpp` / `持平`（百分点差） |

| 指标语义 | 升 ↑ | 降 ↓ | 持平 |
|----------|------|------|------|
| **越高越好**（营业额/去券/主营/客单数/客单价/前台·综合毛利额·毛利率/会员占比/线上占比等） | `🟢↑ +x%` | `🔴↓ -x%` | 不加色 |
| **越低越好**（损耗额/损耗率） | `🔴↑ +x%`（或 pp） | `🟢↓ -x%` | 不加色 |
| **中性观察**（促销销售占比等，仅提示结构） | `↑ +xpp`（达阈再 `⚠️`） | `↓ -xpp` | 不加色 |

未取到对比期 → 该格 `—`，勿臆造。达异常阈可在色标后再加 `⚠️`（提示）或加粗（异常），**不要**用第二套无关 emoji 刷屏。

**日报告**对比键：仅上周同期 = 同星期、差 7 天的经营日（`listMonthDates`，跨月再打上月；**禁止** `listYearDates`、禁止公历自算、**禁止查前一天**）。  
**周/月报告**：列名「较上一周/月」，规则同（只显示比例）。

### 1.2 骨架（照此排；毛利损耗必须带对比列）

```markdown
## {店名} · {日期}（{周几}）· 经营总览

### 销售概览
| 指标 | 当日 | 较上周同期 |
|------|------|------------|
| 营业额 | **232.56 万元** | 🟢↑ +3.2% |
| 去券销售 | **228.10 万元** | 🟢↑ +2.0% |
| 主营 | **210.00 万元** | 🟢↑ +1.5% |
| 客单数 | **2,701** | 🟢↑ +4.1% |
| 客单价 | **86.10 元** | 持平 |
| 会员营业额占比 | **67.0%** | 🟢↑ +1.0pp |
| 线上销售占比 | **7.9%** | — |
| 促销销售占比 | **54.7%** | ↓ -0.8pp |

### 毛利与损耗
| 指标 | 当日 | 较上周同期 |
|------|------|------------|
| 前台毛利 | **28.50 万元** | 🟢↑ +1.0% |
| 前台毛利率 | **12.3%** | 🔴↓ -0.2pp |
| 综合毛利 | **71.20 万元** | 🟢↑ +0.8% |
| 综合毛利率 | **24.6%** | 🔴↓ -0.4pp |
| 损耗额 | **4.90 万元** | 🔴↑ +3.0% |
| 损耗率 | **2.1%** | 🔴↑ +0.2pp |

> **禁止**：省略较上周同期列，或只写当日不写比例。  
> **禁止**：对比列填对照期绝对值；**日报禁止出现「较前一天」列。**

### AI 诊断小结
2～4 句；点最多 3 个关注（阈值未确认用「核心关注」，勿空喊异常）。
```

### 必报字段（内部对照，勿对用户说出）

销售：`turnoverAmt` / `netSalesAmt` / `mainSaleAmt` / `ticketCount` / `ticketPrice` / `memberTurnoverRatio` / `onlineSalesRatio` / `promoSalesRatio`  
毛利损耗：`frontMarginAmt` / `frontMarginRate` / `comprehensiveMarginAmt` / `comprehensiveMarginRate` / `lossAmtAbs` / `lossRateAbs`  
（有亮点再补会员人数、促销前台毛利等。生鲜/常规盈亏深拆、瀑布、低毛利 → **margin-report**，本表不展开。）

## 2. 对比取数与异常

1. 先查**当日** `getShopSaleOverview`  
2. **日报**只再查**上周同期**（同 apiName + 日历键）；失败则该列 `—`。**不查前一天**  
3. 成文：当日绝对值 + 一列比例  

阈值占位（待业务确认）；未确认前可出比例，**禁止**「异常」措辞。

| 指标 | 提示（草稿） | 异常（草稿） |
|------|--------------|--------------|
| 营业额 / 客单数 | \|Δ\|≥8% | \|Δ\|≥15% |
| 客单价 | \|Δ\|≥5% | \|Δ\|≥10% |
| 综合/前台毛利率 | \|Δ\|≥1pp | \|Δ\|≥2pp |
| 损耗率 | 升≥0.5pp | 升≥1pp |
| 促销销售占比 | 升≥5pp | 升≥10pp |

## 3. 自检

- [ ] 标题含店名 · 日期 · 经营总览  
- [ ] 销售概览、**毛利与损耗**均有：当日 / 较上周同期（日报无较前一天）  
- [ ] 对比列**只有** ↑↓% 或 pp，无对比期绝对值  
- [ ] 利好/利空已标 🟢/🔴（损耗升为红、降为绿）  
- [ ] 金额万元 2 位；客单价元 2 位  
- [ ] 未查数阶段外再乱调 MCP；阈值未确认未喊异常
