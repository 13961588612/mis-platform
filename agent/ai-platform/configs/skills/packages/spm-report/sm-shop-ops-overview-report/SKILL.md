# 经营总览主题分析（sm-shop-ops-overview-report）

**只做本主题解读与成文**，不做查数。

- 取数：router → `skill(sm-shop-sale)` → `getShopSaleOverview`
- **禁止**再调销售 MCP；**禁止**另写 apiName
- 加载时机：S1 取数成功后；或由 `sm-shop-ops-comprehensive-report` 按节调用
- 综合报告请用 **`sm-shop-ops-comprehensive-report`**

---

## 1. 版式（诊断页三段式）

输出 **Markdown**。无目标字段则省略目标/进度；禁止 HTML。

### 1.0 数字单位（强制）

| 类型 | 展示 | 示例 |
|------|------|------|
| **金额**（营业额/去券/主营/毛利额/损耗额/促销额/会员营业额等，**不含客单价**） | 接口值为**元** → 除以 10000 → **万元**，**保留 2 位小数**，后缀写 `万元` | `2325600` → **232.56 万元** |
| **客单价** | 仍用**元**，保留 2 位小数，后缀 `元` | **86.10 元** |
| 客单数 / 人数 | 整数（可千分位） | **2,701** |
| 比率 / 占比 | 百分数，保留 1 位小数 + `%`；对比用 `pp` | **24.6%** |

禁止金额用「元」大数或只写「万」且一位小数；禁止客单价改成万元。

```markdown
## {店名} · {时间标签} · 经营总览

### 销售概览
| | |
|:--|--:|
| **营业额** | **232.56 万元** |
| 较上期 | **↑ +10.7%** 🔴 |
| 较同期 | **↑ +3.2%** |

### 核心过程指标
| 指标 | 本期 | 较上期 | 较同期 |
|------|------|--------|--------|
| 客单数 | **2,701** | **↑ +12.0%** 🔴 | ↑ +4.1% |
| 客单价 | **86.10 元** | ↓ -2.3% | 持平 |
| 综合毛利率 | **24.6%** | **↓ -1.2pp** ⚠️ | ↓ -0.4pp |
| 损耗率 | **2.1%** | **↑ +0.6pp** 🔴 | ↑ +0.2pp |
| 促销销售占比 | **54.7%** | ↑ +3.1pp | — |
| 会员营业额占比 | **67.0%** | 持平 | ↑ +1.0pp |
| 线上销售占比 | **7.9%** | ↑ +0.5pp | — |

### AI 诊断小结
…（阈值未确认用「核心关注」，勿空喊异常）
```

标记：升 `↑` 降 `↓`；提示 `⚠️`；异常 `🔴` + 加粗；贴在数值旁。无对比期列写 `—`。

### 必报字段（内部对照，勿对用户说出）

营业额 `turnoverAmt`；客单/客单价；综合/前台毛利率；损耗率；促销销售占比；会员/线上占比等（见 `sm-shop-sale` overview 字段表）。

## 2. 对比与异常

| 类型 | 做法 |
|------|------|
| 同比 / 上期 | 同 apiName 二次查询；键来自日历 |
| % / pp | 金额客流用 %；毛利率损耗促销占比用 pp |

阈值占位（待业务确认）；未确认前可出对比表，**禁止**「异常」措辞。

| 指标 | 提示（草稿） | 异常（草稿） |
|------|--------------|--------------|
| 营业额 / 客单数 | \|Δ\|≥8% | \|Δ\|≥15% |
| 客单价 | \|Δ\|≥5% | \|Δ\|≥10% |
| 综合/前台毛利率 | \|Δ\|≥1pp | \|Δ\|≥2pp |
| 损耗率 | 升≥0.5pp | 升≥1pp |
| 促销销售占比 | 升≥5pp | 升≥10pp |

## 3. 自检

- [ ] 仅总览主题；未查数  
- [ ] 金额（除客单价）均为**万元、2 位小数**；客单价为**元、2 位小数**  
- [ ] 环比贴数值旁；无目标未编造进度  
- [ ] 阈值未确认未喊异常
