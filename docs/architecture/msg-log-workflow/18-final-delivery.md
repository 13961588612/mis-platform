### 只读态的实现（比方案更好）

方案原设想"传 `readOnly=true` 让组件自己克制"，工程师改为**类型层面隔离**：

```typescript
// read-only-form-view.tsx:42
export interface ReadOnlyFormViewProps {
  formCode: string | null | undefined
  formData: string | null | undefined
  // ↑签名里没有 component，也没有 FormProps
}
```

理由：**"传 readOnly 让组件克制"依赖每个业务作者都写对 `if (readOnly) return` —— 人工代码一定会有人忘。**
