## 4. 与问数平台的映射原则

1. **问数只挂 ADS + DIM**：WrenAI 建模只注册 ADS 29 张 + DIM 维表；DWD 明细层不开放给自由问数（防止大表扫、防止口径绕开预计算指标），仅通过"下钻"固定模板或人工取数。
2. **预计算指标优先**：凡表内已有 rate / yoy / mom 字段，问数引导使用预计算列，不让 LLM 现场拼公式（尤其毛利率、复购率、投入产出比、同比）。
3. **同比/环期已物化**：mbr_hall 表带 _yoy/_mom 后缀列，mall 小时表本身就是"同期"表 → 问"同比增长"时优先用这些表，而不是让模型算日期偏移。
4. **分层主题隔离**：智能体 skill 触发时先锁主题域，再带上下文调 wrenai，避免跨域 join 幻觉。
