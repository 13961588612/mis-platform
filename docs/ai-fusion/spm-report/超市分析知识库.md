# 超市经营分析：常见问题与口径说明

这是给**使用超市经营分析**的同事看的说明。当你看到某个指标、某张表、或系统不给今天数据时，用这里的解释对照。

本文只讲已经能问到的经营口径。不讲系统怎么实现。百货商场（百购）不在本文范围。

## 超市经营分析能帮我看什么？

超市经营分析可以按**一家门店**看经营情况，包括：

- 营业额、去券销售、主营、客单数、客单价
- 会员销售占比、线上销售占比、促销销售占比
- 前台毛利、综合毛利、损耗、生鲜盈亏
- 折扣结构、出清、供应商促销分担
- 品类结构、类目角色（利润品/客流品等）、类目 ABC
- 新品 / 重点品 / TOP 品 / 出清品结构
- 经销、联营、租赁
- **周、月**还可以看：库存与订货、低毛利预警、复购会员人数

默认是看**你有权限的某一家店**。有多家店时，系统会请你先选定门店，不会随便拿第一家。

## 超市经营分析现在问不了什么？

下面这些目前没有开放，系统会说明做不到，而不会编一个数：

- **今天以及今天之后**的经营数据（见「为什么查不到今天」）
- 采购、财务总账、一天里按小时的峰谷、坪效、人效
- 单品 ABC、动销率、供应商销售有多集中
- 复购漏斗（买 1 次 vs 买 2 次以上等）
- 把损耗说成「吃掉了毛利」（损耗和毛利是并列科目，不是相减关系）
- 没有统一阈值时，不会轻易说某项「异常」
- 百货商场、通用随意问数（那是别的助手）

日报**不会**出库存、低毛利预警、复购人数。这些只在周报、月报里。

## 超市经营分析为什么查不到今天的数据？

超市经营数据是 **T+1**：只能看到**昨天及更早**已经出数的日期。今天、以及还没过完的周/月，系统不会给数。

请改查昨天，或已经出完数的业务周、业务月。

## 超市经营的日、周、月分别怎么理解？

| 你要看的 | 时间怎么定 | 默认跟谁比 | 特别限制 |
|----------|------------|------------|----------|
| 某一天（日报 / 晨会） | 一个**经营日**，以系统日历为准 | **上周同一星期几**（不是昨天） | 不看出库存、低毛利、复购 |
| 某一周（周报） | **业务周**（不是自己按日历数第几周） | **上一业务周** | 可以看库存、低毛利、复购 |
| 某一月（月报） | **业务月** | **上一业务月** | 同周报 |

「完整经营报告 / 综合诊断」如果没说日还是周，按**月报**理解。

业务周、业务月必须是系统里已经有的。没有这一周、这一个月，就不会去猜一个相邻周月来凑。

## 超市经营日报为什么不是跟昨天比？

日报默认对比的是 **上周同一天**（例如本周四对上上周四），用来看「这个星期几相对平时怎样」。

**不跟前一天比。** 昨天往往是另一个星期几，客流和档期不一样，不适合当日报主对照。

如果系统日历里找不到那个「上周同一天」，对比列会空着或写「无对照」，不会再随便减 7 天去凑。

## 超市经营周报、月报跟谁比？能看同比吗？

- 周报：跟**上一业务周**比（系统周清单里、本期的前一周；若是年初第一周，则用上一年最后一周）。
- 月报：跟**上一业务月**比，规则相同。

不要自己用「周序号减 1」「月份减 1」去推。系统没有这一周/月，就不会编。

**同比**（跟去年同一周、同一月比）只有你明确说要同比时才会做。默认不做同比。

「各周走势 / 月内各周」只有你点名要时才出，并且只看各周的经营总览，不会按周再拆促销、毛利瀑布、库存。

## 超市经营可以要哪些报告？分别有什么？

| 你怎么说 | 会给你什么 |
|----------|------------|
| 某日经营 / 日报 | 销售、毛利损耗、品类 TOP、类目角色、促销、毛利瀑布、生鲜。没有库存、低毛利、复购 |
| 某周经营 / 周报 | 上面这些，再加上类目 ABC、低毛利、库存订货；对比上一周 |
| 某月经营 / 月报 | 和周报结构类似；对比上一月 |
| 只要晨会 / 经营总览 | 销售 + 简单毛利损耗 + 促销占比。不展开瀑布、生鲜、低毛利 |
| 只要促销 | 折扣三列、出清、供应商分担 |
| 只要毛利损耗 | 瀑布、生鲜；低毛利只在周/月 |
| 只要品类 | 结构、四象限、ABC 等 |
| 只要库存订货 | 仅周、月；日报没有 |

一次只出一种报告。说「综合诊断」时按日/周/月出一份完整稿，不会再拆成好几份主题报告拼在一起。

## 超市经营报表上的数字单位是什么？

- **金额**（营业额、毛利额、折扣额、库存额等）：展示为 **万元**，一般保留两位小数。
- **客单价**：仍是 **元**，不是万元。
- 客单数、人数、SKU 个数：整数。
- 比率、占比：百分数，一般一位小数。

本期列写**绝对值**。对比列只写**升了/降了百分之几**或**百分点**，不再写对照期的绝对金额。

## 超市经营里营业额、去券、主营、客单有什么区别？

| 说法 | 含义 |
|------|------|
| 营业额 | 门店销售金额（含券口径） |
| 去券销售 | 扣掉促销券之后的销售 |
| 主营 | 主营商品的销售金额 |
| 销量 | 卖了多少件（数量） |
| 客单数 | 成交了多少笔 |
| 客单价 | 营业额 ÷ 客单数，单位是**元**。不是「一件多少钱」 |
| 会员营业额占比 | 会员贡献的营业额占全店营业额的比例 |
| 线上销售占比 | 线上相对全店的销售结构 |
| 促销销售占比 | 促销销售占营业额的比例（只观察结构，升高不一定是好事或坏事） |

线上分平台、分品类的明细，按**销售发生的日期**来查，和「经营日 / 经营周」不一定同一套日期。

## 超市经营里前台毛利和综合毛利差在哪？

**前台毛利**可以理解为：营业额减去销售成本之后、还没做一堆后台调整时的毛利。

**综合毛利**是前台毛利再经过后台费用、供应商分担、配送加价、物流分摊、股权调整等之后的结果。

毛利率分母不一样，不要混用：

- 前台毛利率（含税）= 前台毛利含税 ÷ **营业额**
- 前台毛利率（去税）= 前台毛利去税 ÷ **主营**
- 综合毛利率 = 综合毛利 ÷ **营业额**

**毛利瀑布**就是把这条链路摊开：营业额 → 减成本 → 前台毛利 → 各项调整 → 综合毛利。每一项会标明对毛利是增加还是减少、增减多少。前台到综合的差额 = 综合毛利 − 前台毛利。

## 超市经营里损耗升高是不是吃掉了毛利？

**不是。** 损耗和毛利是并列记账的，不能把损耗额从毛利里直接扣掉来说「毛利被吃了」。

损耗率 = 损耗金额（取绝对值）÷ **去券销售**。

阅读时：损耗升高一般视为不利；销售、毛利额和毛利率升高一般视为有利。促销占比只看结构变化，不默认标红绿。

生鲜盈亏、常规盈亏是另一组「赚了还是亏了」的数，和损耗相关、但不是同一句话。

## 超市经营里总折扣、促销打折、处理打折是一回事吗？

**不是，三列要分开看。**

| 说法 | 含义 |
|------|------|
| 总折扣 | 折扣合计 |
| 促销打折 | 促销活动产生的打折，不等于总折扣 |
| 处理打折 | 处理品 / 出清相关的打折，也不等于促销打折 |
| 总折扣率 | 对应折扣 ÷ 营业额 |

另外：

- **出清回收比** = 出清前台毛利 ÷ 处理打折。越接近 1，说明出清打折「收回来」得越好。
- **供应商分担率** = 供应商承担的促销折扣 ÷ 总折扣。

## 超市经营周报、月报里库存、滞销、缺货、周转怎么读？

日报没有这些指标。周报、月报可以看：

| 说法 | 含义 |
|------|------|
| 库存金额（去税） | 库存值 |
| 滞销库存 / 占比 | 卖不动的库存及其占库存的比例 |
| 缺货 SKU / 缺货率 | 缺货个数和缺货比例 |
| 周转天数 / 周转率 | 货转得快不快；算不出时会空着 |
| 订货、验收、缺口率 | 缺口率与「订了多少、收了多少」有关；订货为 0 时缺口率没有意义 |
| 退货额、退货率 | 退货情况；上期退货为 0 时会写明是 0，而不是空着 |
| 交叉率 | 去税前台毛利率 × 周转率，综合看「毛利和周转搭在一起」的效率 |

库存升高往往不利于周转。

## 超市经营里生鲜是怎么圈定的？低毛利、复购呢？

**生鲜**：按商品分类里「生鲜」这一支来汇总（分类编号以 1 开头这一套约定），不是随便把某种商品类型都算进去。

会给出生鲜营业额占全店、生鲜主营占全店主营、生鲜前台毛利、生鲜盈亏和常规盈亏。对比时，生鲜主营既要看金额变化，也要看占比变化，不能只报一个金额。

**低毛利预警**（仅周、月）：有多少主营销售落在「低毛利率」口径里，以及它占全店主营的比例。不会再拆到单品。日报没有这项。

**复购**：周、月可以看复购会员人数。日报没有。「买一次 / 买两次以上」的漏斗目前没有。

## 超市经营里品类怎么分？四象限和 ABC 是什么意思？

分类从粗到细一般是：部门 → 柜组 → 大类 → 中类 → 小类。没特别说明时，结构、四象限、ABC 默认看**大类**。

店内占比是**这一家店、这一次结果里**算的。结构表通常按营业额占比从高到低，最多列前 10 个类目，其余会说明「还有 N 个未展开」。

**类目角色（四象限）**是用本店的营业额占比中位数、前台毛利率中位数划十字，不是全公司统一标准：

| 角色 | 怎么理解 |
|------|----------|
| 利润品 | 卖得多，毛利率也高 |
| 客流品 | 卖得多，但毛利率偏低（常用来带客） |
| 结构品 | 卖得不多，但毛利率高 |
| 问题品 | 卖得少，毛利率也低 |

这是**类目**判断，不是单品。

**类目 ABC**只回答一件事：本店这一期里，**哪些类目贡献了大部分营业额**。它不是好坏评分，也不是库存、缺货、毛利等级，更不要和上面的四象限混看（四象限还看毛利率，ABC **完全不看毛利**）。

怎么分的（默认按**大类**）：

1. 把本店本期各个类目，按**营业额从高到低**排成一列。
2. 从最高的那个开始往下加，看「加到这里，已经占全店营业额的百分之几」（累计占比）。
3. 按累计占比切成三档（帕累托常用 80 / 95）：
   - **A 类**：从第一名加起，**累计还没到 80% 之前**的那些类目。它们个数通常很少，却贡献了大约前 80% 营业额，是店里的**头部贡献盘**。
   - **B 类**：接着往下加，累计大约落在 **80%～95%** 这一段的类目。个数比 A 多一些，贡献大约 **15%** 营业额，是**中腰**。
   - **C 类**：再往后剩下的全部类目。累计大约只占全店最后 **5%** 营业额，但类目个数往往很多，是**长尾**。

用一张假数帮助理解（全店营业额当 100，只列几个大类）：

| 按营业额从高到低 | 本类占全店 | 加到这里累计 | 分到哪一档 | 怎么读 |
|------------------|------------|--------------|------------|--------|
| 生鲜 | 30% | 30% | **A** | 卖得最多的一类 |
| 食品 | 25% | 55% | **A** | 仍在凑前 80% |
| 日化 | 20% | 75% | **A** | 累计还不到 80%，仍算头部 |
| 服装 | 10% | 85% | **A** | 加上它才跨过 80%，仍算 A |
| 家电 | 8% | 93% | **B** | 已经过了 80%，还在往 95% 凑 |
| 文具 | 3% | 96% | **B** | 加上它跨过 95%，仍算 B |
| 其余很多小类 | 一共约 4% | 100% | **C** | 每个都不大，加起来才一点点 |

读报表时注意：

- **A 不等于「好品」**，只表示「店里钱主要从这几类过来」。A 太集中，说明生意绑在少数类目上，供给一旦出问题影响大。
- **C 不等于「该砍」**，只表示「卖得散、贡献小」。要不要调整，还要结合四象限、库存、损耗，系统不会单凭 C 就下结论。
- 分档是**这一家店、这一期自己比出来的**，不是全公司统一名单。换店、换周，同一类目可能从 A 变成 B。
- 现在只有**类目** ABC，没有单品 ABC，也没有动销率。

## 超市经营报表对比列里的箭头和颜色怎么看？

- 本期：只写现在的绝对值。
- 「较上周同期 / 较上一周 / 较上一月」：只写升降比例，不写对照期金额。
- 金额、客单：用百分比；毛利率、损耗率、占比：用百分点（pp）。
- 越高越好的指标：升为有利、降为不利。
- 损耗：升为不利、降为有利。
- 促销占比：中性，一般不加红绿。
- 持平不加颜色。
- 两期都有数时，不该空成「—」。只有对照期没取到，才写「—」或「无对照」。

## 问超市经营数据时怎样说更清楚？

尽量带上：**哪家店 + 哪一天/哪一周/哪一个月 + 要看什么**。例如：

- 「朝阳社区店昨天的经营日报」
- 「某店第几周库存和滞销」
- 「某店某月品类里哪些是利润品」
- 「某店上周促销折扣结构和出清回收比」

不要说「今天」「这个月第 45 周」这种系统里可能没有的时间。店名以你权限内的门店为准。
