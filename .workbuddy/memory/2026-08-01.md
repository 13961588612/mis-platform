## 专业中性灰重构（2026-08-01 续10）
- 用户反馈截图「配色不够专业」。
- 问题：页面/容器/表头/偶数行全用 214 色相偏青冷灰，饱和度高显旧；奇数行纯白（0 色相）与偶数行不同色相，像补丁；表头与容器同色无层次；侧边栏与页面背景几乎同色边界模糊。

- token（globals.css）：

  - 浅色：`--background 220 14% 95.5%`、`--border 220 13% 90%`、`--table-surface 220 14% 98%`、`--table-header 220 14% 96%`、`--table-row 0 0% 100%`、`--table-stripe 220 14% 99%`、`--table-hover 220 14% 94%`；`--sidebar 222 47% 11%`。
  - 暗色：`--background 222 40% 6%`、`--table-surface 222 40% 11%`、`--table-header 222 40% 14%`、`--table-row 222 40% 13%`、`--table-stripe 222 40% 11.5%`、`--table-hover 222 40% 18%`；`--sidebar 222 47% 8%`。
- tailwind.config.ts 新增 `table-header` 颜色映射。
- 组件：所有表格 `<thead>` 的 `bg-table-surface` 改为 `bg-table-header`（tree-table/list-page-skeleton/dashboard/log-pages/module/org/role/dict）；admin/user 已同步改但含 AI 表单 WIP，未纳入提交。
- 效果：页面背景明确灰 → 表格容器极淡灰 → 表头浅灰 → 奇数行白 → 偶数行微灰 → hover 灰，层次清晰；侧边栏深色与主区边界清晰。
