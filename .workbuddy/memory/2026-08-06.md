## 接口模块 表头"上移"精细修复（16:10）
- 用户复测：滚轮能滚了、表头也不抖了，但**滚到顶部时表头距 Tab 约 12px 空白、向下滚后吸顶紧贴 Tab 0px**——两状态间有视觉"跳动"，用户感为"表头向上移动了"。
- 根因：滚动容器内 `<div className="p-3">` 的顶部 12px padding。sticky th 未激活时在 p-3 内部（距滚动容器顶 12px = 距 Tab 下 12px）；激活后被钉到滚动容器顶（0px）。两态 12px 视觉差。
- 修法：把 `p-3` 改为 `pt-0 px-3 pb-3`（去掉顶部 padding，保留左右底部 12px 留白）—— 表头永远紧贴 Tab 区域（0px 偏移、永远不动），左右和底部仍有 12px 视觉留白。

## BugFix：BFF→ai-platform `GET /api/v1/agents` HTTP 401（23:1x，团队 software-bugfix-agents-401）
